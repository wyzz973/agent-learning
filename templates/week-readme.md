## 目标

## 自检标准

不看资料能独立做到才算过。写可验证的行为，不写"理解了 XX"：

- [ ] 例："能手写一个带条件分支和循环的 StateGraph，不用 create_agent"

## Build It — 手写版

从零实现，不用框架。说明我实现了什么、踩了什么坑。

## Use It — 框架版

用框架做同一件事，然后**对比**：

| 我手写的 | 框架的做法 | 差异说明了什么 |

| | | |

这一节是本周价值最高的部分。框架替我做掉的每一件事，都要能说出它解决的是什么问题。
