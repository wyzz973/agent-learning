# D04 · w04 · 把 Python 函数接成工具

## 今天要做什么

独立组合校验/搜索/结果；跑工具热身；运行本地 agent_demo。

产物/编辑位置：`ex2_search_tool.py::search_repository`。先读[当周教材](../../weeks/w04-python-tools/README.md)，确认三段坡道中哪些由你写。

## 为什么这样做

把散落的处理动作组合成可调用能力。

## 核心思想

函数通过参数和返回值协作，框架负责连接。

## 能学到什么

Python：列表、字典、for/if、in/or、append、return。Agent 能力：把 Python 函数接成工具。只学习本任务用到的写法；术语到[词典](../../GLOSSARY.md)，接口到[API 手册](../../API_GUIDE.md)按词查。

## 前置条件

完成 [D03](D03.md) 的必要验收；不懂就接着原任务练。

## 60 分钟步骤

1. **5 分钟**：不看答案说出上次任务的输入、输出和一个失败情况。
2. **10 分钟**：读本课所需热身/示范，先预测输出，再运行；让导师分清语法与 API。
3. **30 分钟**：独立组合校验/搜索/结果；跑工具热身；运行本地 agent_demo。每次只改一小处、运行一次。
4. **10 分钟**：按下面验收核对结果，用自己的话说明“哪个数据交给了谁”。
5. **5 分钟**：在学习状态留下实际证据、卡点与下一步；问答由模型逐字记录。
