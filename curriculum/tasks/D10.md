## 今天要做什么

**独立写完 `ex1_files.py` 里的 `successful_paths`，然后填本周 README 的 Use It 与 Ship It。**

1. 写 `successful_paths`：从一批工具结果里挑出成功的，只返回路径

## 为什么这样做

`successful_paths` 是把 w04 的筛选结构迁移到新数据上——**同样的 for/if/append/return，换了一种记录**。能迁移才说明真的会，不是记住了 w04 的代码。

## 核心思想

失败路径和成功路径一样重要。模型只能根据你返回的东西做判断，错误信息写得含糊，它就只能瞎猜。

## 能学到什么

遍历字典列表、按字段筛选、只取需要的字段返回。都是 w04 练过的写法，换了数据。
