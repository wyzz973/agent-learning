# D10 · w05 · 复盘数据流与失败路径

## 今天要做什么

用空关键词/缺文件/连续调用验证；重写工具索引并画四类消息。

产物/编辑位置：`本周 README 的 Use It/Ship It`。先读[当周教材](../../weeks/w05-files-loop/README.md)，确认三段坡道中哪些由你写。

不要只验证理想路径。

## 核心思想

每个循环都应能结束，每个结果都能追到来源。

Python：Path、try/except、JSON、函数索引、async/await。Agent 能力：复盘数据流与失败路径。只学习本任务用到的写法；术语到[词典](../../GLOSSARY.md)，接口到[API 手册](../../API_GUIDE.md)按词查。

## 前置条件

完成 [D09](D09.md) 的必要验收；不懂就接着原任务练。

1. **5 分钟**：不看答案说出上次任务的输入、输出和一个失败情况。
2. **10 分钟**：读本课所需热身/示范，先预测输出，再运行；让导师分清语法与 API。
3. **30 分钟**：用空关键词/缺文件/连续调用验证；重写工具索引并画四类消息。每次只改一小处、运行一次。
4. **10 分钟**：按下面验收核对结果，用自己的话说明“哪个数据交给了谁”。
5. **5 分钟**：在学习状态留下实际证据、卡点与下一步；问答由模型逐字记录。

先定位卡在数据形状、语法、调用还是返回；展示最小输入、预期输出和第一条错误。让导师先给方向或相似例子，保留自己的实现机会。60 分钟到仍未完成就续做此任务，不叠加下一课。
