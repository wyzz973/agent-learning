# D09 · w05 · 同一工具运行两种 agent

## 今天要做什么

**用同一个工具，分别跑你手写的循环和 LangChain 的入口，对比两者的差别。**

1. 跑 `--mode tool`：只执行 Python，不涉及模型
2. 跑 `--mode loop`：你 D08 写的循环，配固定回放剧本
3. 跑 `--mode langchain`：框架的 `create_agent`，同一个工具
4. 有 key 的话再加 `--live` 跑一次真实模型

## 为什么这样做

同一个工具在两种 agent 下都能用，说明**工具和循环是可以分开的**。分不清「回放剧本」和「真实模型」，就会把别人写死的脚本当成模型的能力。

## 核心思想

工具是你的，循环可以是你写的也可以是框架的。换掉循环不需要改工具。

## 能学到什么

命令行参数、同一份工具接到不同 agent、区分回放与真实调用。今天不写新函数。

## 前置条件

D08 的 `run_agent` 三条测试已通过。

## 60 分钟步骤

时间分配见 [导师执行手册](../TEACHING.md#每日-60-分钟)，今天的内容是：

| 阶段 | 今天做什么 |
|---|---|
| 回忆 5 分钟 | 说出 D08 循环的出口条件 |
| 热身 10 分钟 | 读 `scripts/run_course_app.py` 的三种模式各做了什么 |
| 自己写 30 分钟 | 依次跑三种模式，记录每种模式下「谁在决策、谁在执行」 |
| 验收 10 分钟 | 按下面的标准核对 |
| 交接 5 分钟 | 记下卡点 |

```sh
uv run python scripts/run_course_app.py --mode tool
uv run python scripts/run_course_app.py --mode loop
uv run python scripts/run_course_app.py --mode langchain
```

## 验收标准

- [ ] 三种模式都能跑出结果，并说出各自调用了什么、没调用什么。
- [ ] 能指出哪一步是回放剧本、哪一步是真实的文件读取。
- [ ] 能说清 `--mode loop` 和 `--mode langchain` 的输出为什么可以一样。
- [ ] 如果用了 `--live`，记录实际模型名与一次完整的工具调用。

## 卡住怎么办

某个模式报错时，先看它依赖你的哪个函数还没完成。入口在学习代码未完成时会明确报错，这是设计好的，不是环境坏了。

## 资料与边界

- 回放剧本不证明模型的规划能力，只证明你的代码能被正确驱动。
- `--live` 会产生真实费用，且需要模型支持工具调用。
- 通用规则见 [根规则](../../AGENTS.md)。
