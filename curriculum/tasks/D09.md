# D09 · w05 · 同一工具运行两种 agent

## 今天要做什么

用回放模型运行手写循环与 LangChain 入口；有 key 再选 --live。

产物/编辑位置：`scripts/run_course_app.py --mode loop`。先读[当周教材](../../weeks/w05-files-loop/README.md)，确认三段坡道中哪些由你写。

## 为什么这样做

识别自己循环与框架代劳的部分。

## 核心思想

同一能力可换编排方式，不需要重写工具逻辑。

## 能学到什么

Python：Path、try/except、JSON、函数索引、async/await。Agent 能力：同一工具运行两种 agent。只学习本任务用到的写法；术语到[词典](../../GLOSSARY.md)，接口到[API 手册](../../API_GUIDE.md)按词查。

## 前置条件

完成 [D08](D08.md) 的必要验收；不懂就接着原任务练。
