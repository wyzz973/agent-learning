# D20 · w07 · 首月作品验收与重写

## 今天要做什么

从新终端按 README 跑工具/循环/图；本人改一条需求再测试；写复盘。

产物/编辑位置：`本周 README 的首月验收单`。先读[当周教材](../../weeks/w07-evaluation/README.md)，确认三段坡道中哪些由你写。

## 为什么这样做

把所学变成可独立运行和解释的作品。

## 核心思想

需求到结果再到验证形成闭环。

## 能学到什么

Python：成员检查、计数、除法、BaseModel、model_validate。Agent 能力：首月作品验收与重写。只学习本任务用到的写法；术语到[词典](../../GLOSSARY.md)，接口到[API 手册](../../API_GUIDE.md)按词查。

## 前置条件

完成 [D19](D19.md) 的必要验收；不懂就接着原任务练。

## 60 分钟步骤

1. **5 分钟**：不看答案说出上次任务的输入、输出和一个失败情况。
2. **10 分钟**：读本课所需热身/示范，先预测输出，再运行；让导师分清语法与 API。
3. **30 分钟**：从新终端按 README 跑工具/循环/图；本人改一条需求再测试；写复盘。每次只改一小处、运行一次。
4. **10 分钟**：按下面验收核对结果，用自己的话说明“哪个数据交给了谁”。
5. **5 分钟**：在学习状态留下实际证据、卡点与下一步；问答由模型逐字记录。

开始/检查命令（仓库根目录）：

```sh
./check.sh --week w07
```

完整运行与可选真实模型命令以当周 README 为准。

## 验收标准

- [ ] 离线完整入口通过；有 key 时补真实模型证据；未知能力如实列出。
- [ ] 本人能解释核心思想，指出一个容易写错的地方。
- [ ] 状态记录使用实际结果，未完成/未运行明确标注。迁移或重写需要本人动手。

这是本周复盘课：关闭原实现，换一组输入重写本周最关键的一个小函数；在 notes/weekly 的对应文件记录查过的资料和真实卡点。

## 卡住怎么办

先定位卡在数据形状、语法、调用还是返回；展示最小输入、预期输出和第一条错误。让导师先给方向或相似例子，保留自己的实现机会。60 分钟到仍未完成就续做此任务，不叠加下一课。

## 资料与边界

- [Anthropic：Demystifying evals for AI agents](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents)：2026 年工程文章；任务、评分与完整运行轨迹分开。

- [Anthropic：Effective context engineering](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)：上下文选择与外部证据管理，不把更长上下文等同于更可靠。

资料查阅每次不超过本任务的 10 分钟；不要同时刷完整课程。本卡的时间分配是针对你的基础与工作时间作出的教学安排，不是来源承诺的学习速度。
