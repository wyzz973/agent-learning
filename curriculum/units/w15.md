# w15 · 综合应用与自主开发验收

阶段：结业：闭环复现。预计五次必修学习，共五小时；未达标顺延。

## Build It — 自己实现

先用 模块拆分、测试驱动、阅读文档与定位错误 完成本周任务中的小函数，再接入已有应用。

## Use It — 对照框架与范式

比较本周手写行为与官方接口的责任边界，说明框架做了什么、哪些判断仍由你的代码负责。资料查阅见各日任务。

## Ship It — 验收并交接

独立讲解数据流；现场改需求与修一个错误；演示部署/恢复/回归；标记薄弱项；综合闭环通过；列出仍需练习的能力；不宣称已经掌握所有前沿技术。本周结果加入同一仓库助手，复测旧能力再交接。
