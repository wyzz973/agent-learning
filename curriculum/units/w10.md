# w10 · MCP 与 Skills 扩展

阶段：拓展：互操作。预计五次必修学习，共五小时；未达标顺延。

## Build It — 自己实现

先用 进程、stdin/stdout、异步上下文、装饰器复习 完成本周任务中的小函数，再接入已有应用。

## Use It — 对照框架与范式

比较本周手写行为与官方接口的责任边界，说明框架做了什么、哪些判断仍由你的代码负责。资料查阅见各日任务。

## Ship It — 验收并交接

在两个可用客户端执行同一只读任务；缺客户端则独立 SDK 客户端实测并注明；工具结果一致且差异可解释；不能把未运行的客户端写成已验证。本周结果加入同一仓库助手，复测旧能力再交接。
