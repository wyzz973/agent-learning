# w14 · 服务接口、界面与部署

阶段：工程：交付。预计五次必修学习，共五小时；未达标顺延。

## Build It — 自己实现

先用 请求模型、依赖注入基础、异步迭代、配置 完成本周任务中的小函数，再接入已有应用。

## Use It — 对照框架与范式

比较本周手写行为与官方接口的责任边界，说明框架做了什么、哪些判断仍由你的代码负责。资料查阅见各日任务。

## Ship It — 验收并交接

模拟配置错误和服务重启；验证持久状态；执行一次版本回退；有实际回滚证据；本地验证与公共部署状态分开。本周结果加入同一仓库助手，复测旧能力再交接。
