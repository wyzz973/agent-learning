# w08 · 知识检索与 RAG

阶段：拓展：知识。预计五次必修学习，共五小时；未达标顺延。

## Build It — 自己实现

先用 文件遍历、切片、枚举、列表排序 完成本周任务中的小函数，再接入已有应用。

## Use It — 对照框架与范式

比较本周手写行为与官方接口的责任边界，说明框架做了什么、哪些判断仍由你的代码负责。资料查阅见各日任务。

## Ship It — 验收并交接

加入同义/否定/无答案样例；本人换一份文档重建索引；基线与增强结果可比较；不会只凭一题变好宣布提升。本周结果加入同一仓库助手，复测旧能力再交接。
