# 完整课程入口

从当前 [学习状态](../COURSE_STATE.json) 进入，命令 `uv run python scripts/learn.py` 只显示当天任务。

完整路线是 **12 个学习周、60 次学习，约 60 小时**；每次最多一小时，周末不计入必需时间。前三周历史课程不计入这 60 次。一个月先交付第一版应用，后续继续完成前沿能力与工程闭环。
