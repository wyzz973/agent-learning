# 交换站 · 分享工具和方法教学约定

先读根AGENTS.md和当前state/catalog。学习者零预设，必要Python、API与素材都在当前Notebook交代。

本区域的情景目标：把资料工具与核查方法交给分馆，比较成熟装配方式。

技术范围：MCP、Skills、按需工具发现、DeepAgents。每个task必须有林禾或访客委托、具体障碍、本人控制点、实际产物、对照和迁移。教师示范与本人答案分开，角色/工具/调度/评估prompt都符合雾岛情景，不能为剧情成功伪造结果。

planned/draft不当作可学习教材。机器通过、本人解释和迁移分别记录；写出作品后才展示对应能力，CLAUDE.md只链接本文件。
