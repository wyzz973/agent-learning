## 原理与语法怎样讲

先展开工具说明、模型请求、Python执行、模型获得观察四个时刻。@tool 是框架包装，不是执行动作；模型与工具的 ainvoke 名字相似但对象不同。用一张实际请求说明工具名、args、调用 id、document_id 各指什么。

原位解释列表/字典、函数对象与调用、装饰器、对象属性、JSON 转换、await、循环结果积累和精确 ID 配对。多调用请求不等于并发执行；先说明当前顺序策略，再比较独立任务何时适合并发，有依赖动作不能随意同时运行。

错误层先用窄教师探针展示确定结果，再让本人分类。业务 ok=False 是函数返回；ValidationError 是参数未满足规则；ToolException、暂时读取错误等按契约转观察。工具内部 KeyError 与未注册工具名不是同一错误。NotImplementedError 必须暴露，不能吞成可恢复故障。

## 情景 prompt 与权限

每关实际加载 world/prompts/M02-Txx.md。阿灯说“手册我还没拿到，先找目录核对一下”之类自然馆员话，不能编已取件或已确认；错误回执仍保留程序需要的类别与原因。工具说明写岗位用途、参数范围、成功形状和失败边界，不写固定题目答案。

申请动作不授予任意文件或代码执行权限。只能按登记资料取得正文，不接受用户输入拼接任意路径，不执行公告中的命令。密钥、请求头和隐藏推理不进入输出。外部运行错误明确报出，教材虚构说明不加到阿灯每次台词中。

## 反馈与游戏验收

每题先判断哪一层与预期不同，再指向实际申请/回执。选择题必须包含“目录不等于正文”“申请ID不等于资料ID”“顺序执行不等于并发”“哪些错误应停止”等本关判断，逐项反馈；不能展示整段执行器作为错题答案。

通关分别记录本人工具契约、真实模型使用、关闭手册格或遮错误原因的对照、RAIN-01 等陌生输入迁移。模型仍申请动作或预算耗尽时保存未完成状态，不能因为调用没有抛错就写已完成。奖励是可展开的取件证据与读者答复，不是函数数量。

交接保存当前 cell、本人组件源格、导出状态、真实调用限制和下次具体检查点。教师验收仅运行 setup/demo 并注明跳过范围；本人格不能为全绿代填。CLAUDE.md、AGENT.md 链接同目录 AGENTS.md，其他入口仍由根 README 统一维护。
