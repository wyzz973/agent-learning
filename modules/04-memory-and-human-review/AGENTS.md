# 值班室 · 交班不失忆教学约定

先读根AGENTS.md和当前state/catalog。学习者零预设，必要Python、API与素材都在当前Notebook交代。

本区域的情景目标：断电后接续委托，记住确认信息，保留可核对的经验。

技术范围：检查点、HITL、长期记忆、上下文、Reflexion。每个task必须有林禾或访客委托、具体障碍、本人控制点、实际产物、对照和迁移。教师示范与本人答案分开，角色/工具/调度/评估prompt都符合雾岛情景，不能为剧情成功伪造结果。

planned/draft不当作可学习教材。机器通过、本人解释和迁移分别记录；写出作品后才展示对应能力，CLAUDE.md只链接本文件。
