## 机制推导与语法梯度

先把同一咨询的输入、状态更新、下一站并排走一遍，再引入完整图。State 是工作数据容器，不是 messages 全称；Node 返回更新，Edge 控制顺序，reducer只负责字段合并。至少有覆盖与追加对照，指出重复追加、旧状态和不完整字段的实际后果。

原位讲 TypedDict、Annotated、列表合并、字典更新、函数返回、async/await。先用窄固定流程展示运行，再减少指导让本人增加条件/回边，不突然让零基础同时处理全部陌生概念。可以提供状态表、输入输出和分层提示，不能提供与本人整题等价的隐藏完整图。

calls 为模型次数，recursion_limit 为图步数，二者都不等于工具数。没有新申请的正常结束、预算耗尽、异常、取消分别记录。工具执行器返回 ToolMessage 后还需将观察交给模型，不能将这份回执当成最终答复；图迭代停止不自动代表委托完成。

M03-T03 解释 yield、async for、create_task、wait、cancel、finally 与 monotonic 后再使用。停止等待不等于取消执行；需要请求取消并等待退出。保留本地清理证据，不能将它扩大为供应商服务器已经停止计算。

## prompt 与复用配置

实际加载 world/prompts/M03-Txx.md 并在模型节点使用。复用已导出图时，明确当前岗位 prompt、模型与注册表从哪来；如临时覆盖配置，finally 恢复，不能只显示当前页 prompt 而节点仍沿用旧固定委托。运行输入附当前问题和目录，不在控制逻辑硬编码取件顺序。

阿灯自然说明已取到什么、还缺什么、为何暂时停下；程序事件描述实际阶段，不编百分比或隐藏推理。完整 AIMessage 可留内存用于协议，公开轨迹只挑正文、工具请求、回执ID、状态和必要计数，不 dump 全部响应元数据。

## 选择题、作品与交接

原理题针对状态/消息、合并、回边与停止，迁移题要求判断新问题或故障该改变数据、工具还是控制。反馈给出误解原因与应检查的状态，不贴本人函数答案。答对选择题不代替真实分支、回执和取消验收。

作品是路线图、咨询轨迹、综合答复和取消回执；必须来自本人图与观察器。每次对照只改变一条关键边或一个条件，恢复后再验证。重用组件发生退化应报告，不强行解释为更先进架构。

交接说明当前 cell、本人建造器是否已导出、实际运行配置、已发生路径与未完成项。教师静态检查及 setup/demo 实跑分开记录，本人占位不处理为工具错误。只在本课程允许的资料与输出范围操作，不引入任意执行能力。CLAUDE.md 和 AGENT.md 只链接 AGENTS.md。

| Task | 核心机制 | 本人交付与检查 |
|---|---|---|
| M03-T01 | State保存工作数据，Node返回更新，Edge决定执行路线；区分workflow与agent。 | 有资料与无资料两条路径都实际发生，本人能指出条件来自哪项状态；未走答复分支时没有假冒模型回答。 |
| M03-T02 | 模型提出动作、程序执行、观察进入状态、再次决定；停止是显式路径。 | 真实轨迹出现不同资料的观察以及观察后的模型调用；正常结束与上限停止有不同状态，最终答复可回到原文。 |
| M03-T03 | 公开运行事件和预算是控制系统的一部分；停止原因也属于结果。 | 最终答案出现前能观察到实际阶段；取消或触及边界时明确停止，产物没有伪造成功标识，并检查相关工作已结束。 |
| M03-T04 | 并行分支、reducer、fan-in与确定性；子图是边界而非新权限。 | 核对本页断言、真实输入和来源；选择题与代码迁移分开记录。 |
