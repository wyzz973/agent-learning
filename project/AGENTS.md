# project 模块教学约定

遵循[根教学协议](../AGENTS.md)与[开馆作品契约](README.md)。读者从零开始，角色为学习者、助手阿灯与馆长林禾；用当前委托引入新概念，不预设任何编程或 agent 经验。

## 当前 Notebook 必须自足

必需素材、写法、接口说明、执行步骤和本人练习在当前页交代。素材可从 world 或本课程产物读取，但当前页要定位并展示实际输入。

若本课程某段本人实现尚未完成，在本页明确函数目标、输入输出、待补位置与验证位置，保留本人动手机会。不得要求学习者四处找文件，也不能通过教师参照、默认回退或隐藏导入秘密补答案。

## 积累与真实接续

本人完成并验证的代码有复用需求时，才整理到 project。保留来源 task（任务）、cell（单元格）、本人实现与解释证据、实际调用结果和复用理由。导师可整理包装、文档与检查，不能代写核心控制逻辑或把教师代码标成本人代码。

下游必须真正消费对应产物，记录来源与实际去向；不能只展示输入后切换固定答案。重复运行建立独立记录，迁移实验与主线作品隔离。虚构馆务标明 world 来源；真实技术研究保留公开原文依据。

## 进度与交接

机器可运行、本人能解释、迁移成功分别登记，不自动认定掌握。教师示范、本人实现、机制对照与迁移运行分别记录；奖励只对应实际产物与可验证能力。

不同模型或 harness 读取[instructor/state.json](../instructor/state.json)，围绕当前 Notebook、单元格、本人代码、实际结果与下一步交接。工作区、会话和用户身份在需要时于当前页解释，不能混用作教学成绩。CLAUDE.md 保持指向本文件，不维护第二份规则或入口。
