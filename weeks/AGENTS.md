# weeks 模块规则

先读../AGENTS.md 与根 COURSE_STATE.json。

学习代码区。遵守根目录三段坡道与中文注释规范，未知语法先进入 warmup。w01～w03 冻结；跨周测试独立进程。每个新周有独立规则入口与复盘。

CLAUDE.md 链接本文件，不维护另一份规则。

## 练习编号与待创建文件

每个学习者要写的函数，上方注释标 `── 练习 N/总数 · Day N ·`，教师示范标"示范（不编号）"。编号按本周的学习顺序连续排，跨文件也连续。

当周 README 顶部放一张读的顺序索引表，列出每个文件什么时候用、含哪个练习。**需要学习者自己创建的文件单独列出，并说明给不给骨架**：隔天重写这类验收任务不给骨架也不给签名，给了就失去迁移检验的意义。

文件名不用数字前缀：被 import 的模块名不能以数字开头，顺序靠索引表和文件首行标注表达。
