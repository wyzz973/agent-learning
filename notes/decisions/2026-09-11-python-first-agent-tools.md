# Decision: 用小工具的重复写作打通 Python 与两条 agent 路线

Status: superseded — 见 [完整闭环课程](2026-09-11-complete-agent-curriculum.md)

## Problem

学习者反馈前三周已学完、核心思想能理解，但很多 Python 仍写不出来；长期目标是 Pi 类 coding agent，以及用 LangChain / LangGraph 开发 DeerFlow 类应用。两条方向都依赖可独立编写的工具逻辑。

[w02 复盘](../weekly/w02.md) 与 [w03 复盘](../weekly/w03.md) 反复出现把集合当元素、丢弃返回值和遗漏 return。原 w04 同时安排结构化输出、真实文件、公开 API 和 SQLite，可能继续堆高新概念，无法直接验证这些基础是否已经稳固。这是基于反馈和记录的教学判断，不是对学习能力的测量结论。

## Decision

保留“三段坡道”与“先语法后逻辑”，并加入**缩小题量、同一数据反复写、隔天换数据重写**。w04 只训练一个内存仓库搜索工具：两个主练习、四个学习者函数。判断阶段完成时同时看测试、返回值解释和隔天重写。

Python 是两条方向的共同学习语言。w04 先把工具逻辑写稳；后续用同一个工具对比手写循环与 LangChain / LangGraph 编排。项目目标借鉴能力和结构，不要求照抄上游语言或全套功能。

模型最终结构化输出、持久化、RAG 的推进以基础自检为前提；它们不构成本周必做量。w05 开周先根据 w04 独立写作证据定内容。详情统一放在 [学习路线](../../LEARNING_PATH.md) 与 [w04 README](../../weeks/w04-python-tools/README.md)。

## Alternatives rejected

- **原题量加更长 warmup。** 已经有热身，学习者仍报告不会独立写；继续增加阅读量无法代替回忆和写作练习。
- **坚持复杂度、只把 TODO 切小。** 容易训练局部填空，整段数据流仍不会组装。因此保留独立函数，降低单个函数包含的概念数量。
- **脱离 agent 单开 Python 通识路线。** 当前四个基础动作可以直接放进用户目标需要的搜索工具，没必要拆成两套每日任务。
- **立刻复刻 Pi 或 DeerFlow 完整工程。** 模型适配、界面、持久化与编排会掩盖基础写作问题。
- **只跑真实模型评判完成。** 模型能回答不等于学习者能重写；确定性测试与隔天迁移是单独的证据。

本决定承接并替代 [坡道决策](2026-09-06-scaffolded-exercise-gradient.md) 与 [热身决策](2026-09-07-separate-syntax-from-logic.md) 中“无需缩减语法或练习量”的判断，保留其坡道、热身和答案由学习者完成的安排。

## Verification

教材验证与教学效果分开：两份热身及已完成示范可运行，8 条示范/连接测试通过，13 条练习规格因 TODO 未完成而失败，`./check.sh --wip` 通过。连接测试用替身验证消息连接、错误反馈与四次模型调用上限，不算学习者实现；未调用真实模型。

教学效果尚未验证：待本人记录 Day 1 诊断和 Day 5 隔天重写；能否在新数据上独立组织循环与返回值，才决定此安排是否有效。
