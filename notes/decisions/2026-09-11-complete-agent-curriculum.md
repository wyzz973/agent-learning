# Decision: 完整闭环优先，以首月作品作为里程碑

Status: implemented

## Problem

用户要求完整 agent 开发能力与前沿范式，明确不能因为首月时间短删减必要内容；同时工作日每天最多一小时，Python 基础薄弱，且会切换模型/harness 学习。

## Decision

完整路线从 w04 起共 12 个学习周、60 次一小时任务。首月形成可运行应用与评估闭环；后续完整覆盖 RAG、记忆/恢复、MCP/Skills、规划协作、上下文/权限、评估观测、服务部署与综合验收。每日任务、产物与验收预先写定，后续代码在开周按本人证据准备并实测。

所有可编辑教材使用中文注释；根与模块 AGENTS.md 为唯一规则文本，CLAUDE.md 指向同目录文件；实际进度与材料准备分开，用统一状态和入口交接。

src/agentlab/course_runtime.py 属于教师连接设施：多周复用同一套文件/搜索工具与启动逻辑，调用本人实现，避免跨周复制练习答案。这是本次提升到 src 的理由，不意味着学习者已完成工具。

## Alternatives rejected

- 四周压缩全部深度：每天一小时无法诚实保证全部掌握，会再次堆叠语法与框架。
- 因时间短删掉协议、协作或部署：违背完整闭环目标，无法验收实际应用交付。
- 一次生成所有后续周的实现：会忽略尚未知的基础卡点，还容易让模型把教师代码当成学习者能力；全部任务契约已确定，后续示范粒度按开周证据调整。
- 各 harness 私有记忆各记一套：易漂移，换模型必须依赖仓库里的共同状态与证据。

## Verification

以课程结构检查、60 张任务卡预算/顺序、规则链接、当前四周热身和教师连接测试验证教材；练习占位符保留失败。课程效果、跨第三方 harness 实际遵循情况、后续部署与学习者掌握都需未来实测，不能提前确认。
